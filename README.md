# Predicting Profit Using R&D Spend, Administration, Marketing Spend, and State

Building a beginner-friendly Multiple Regression Model in Python using Scikit-learn to predict a (fictional) Company's Profits using disclosed Feature values.
A heatmap, among other techniques, was used to evaluate predictor features and decide on an optimal approach to Model-building.

Model Evaluation was done using Model Coefficient Extraction + R-Squared Score interpretation, and a Scatterplot + Line plot to Evaluate Actual VS Predicted values for the Profit Estimation Model.
